# v1.2.x series (next stable)

## v1.2.0 (upcoming release)

### Changed

* Improved CLI output in narrow terminals ({ghpr}`563`).
* Improved {func}`.mi_render` progress bar description to make more explicit
  ({ghpr}`574`).
* ⚠️ 📖 The aerosol data format is upgraded to the new
  {ref}`Aer-Core v2 <sec-data-formats-aer_core_v2>` format ({ghpr}`575`).
* ⚠️ The {class}`.ParticleLayer` now uses a {class}`.ParticleProperties` to
  store its data. The `dataset` parameter is renamed `particle_properties`
  ({ghpr}`575`).

### Fixed

* Improved error messages when initializing a {class}`.MolecularAtmosphere` with
  an incorrect value for the ``absorption_data`` parameter ({ghpr}`566`).
* {class}`.SolarIrradianceSpectrum` now accepts various datetime-like objects
  for its `datetime` argument ({ghpr}`572`).
* Restored variance computation for all stokes components ({ghpr}`571`).
* Fix {func}`.cache_by_id` to avoid updating state when evaluation raises
  ({ghpr}`574`).
* Fix a bug where {func}`.unstack_mdistant_grid` would not work with 1D arrays
  ({ghpr}`574`).
* Fix incorrect error message in {func}`.is_positive` validator ({ghpr}`574`).
* 🖥️ The `osx-arm64` environments now use Conda binaries for the netcdf-4
  library ({ghpr}`574`).

### Added

* Added {class}`.EOVolPathIntegrator` that implements the DDIS variance
  reduction technique from {cite:t}`Buras2011EfficientUnbiasedVariance`
  ({ghpr}`565`).
* Added the `extremum_resolution` parameter to {class}`.AbstractHeterogeneousAtmosphere`,
  which introduces local extremum structures to Eradiate, improving performance
  for spherical shell atmosphere and future 3D volumes ({ghpr}`568`).
* Added residual ratio tracking transmittance estimation, accessible through the
  `use_rrt` parameter in the {class}`.Atmosphere` interface ({ghpr}`569`).
* Added the {class}`.ParticleProperties` class to provide aerosol data lookup
  and interpolation ({ghpr}`575`).
* Added aerosol data conversion functions in the {mod}`eradiate.data.convert`
  module ({ghpr}`575`).
