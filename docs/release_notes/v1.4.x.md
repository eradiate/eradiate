# v1.4.x series (next stable)

## v1.4.0 (upcoming release)

### Added

* ⚠️ Added experimental LLVM operational modes `llvm_mono_double`,
  `llvm_mono_polarized_double`, `llvm_ckd_double` and
  `llvm_ckd_polarized_double`. They select the corresponding `llvm_*` Mitsuba
  variants, which must be enabled in the kernel build. These modes are not
  covered by the test suite's mode fixture groups.
